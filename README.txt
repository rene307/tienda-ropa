CAMBIOS RÁPIDOS

1. NOMBRE
Busca "Valentina" en index.html y reemplázalo por el nombre artístico.

2. WHATSAPP
En script.js cambia:
whatsapp: "569XXXXXXXX"

Ejemplo:
whatsapp: "56912345678"

3. FOTOS
En index.html reemplaza las URL dentro de:
<img src="...">

También puedes guardar fotos propias dentro de una carpeta /img y usar:
<img src="img/foto1.jpg">

4. TEXTO
Puedes modificar libremente Sobre mí, ciudad y datos generales.

5. PUBLICACIÓN
Al ser una web estática puede publicarse directamente en Netlify.
También puede alojarse en Render como Static Site.

6. VIP
El botón VIP actualmente abre WhatsApp.
Para crear llaves temporales o claves con vencimiento se necesita backend.
